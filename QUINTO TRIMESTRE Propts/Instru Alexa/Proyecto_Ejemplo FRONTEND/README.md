# Proyecto Ejemplo (frontend React + backend Express + MySQL)

1. Ejecuta `backend/schema.sql` en MySQL Workbench.
2. Backend:  cd backend && npm install && npm run dev   (puerto 1450)
   - Revisa en `conexion/bd.js` que usuario/contraseña coincidan con tu MySQL.
3. Frontend: cd frontend && npm install && npm run dev  (http://localhost:5173)
