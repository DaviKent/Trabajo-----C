5.1

El Box Model: todo es una caja

En CSS cada elemento HTML es una caja rectangular compuesta por cuatro capas concéntricas. Entender estas capas es la base de todo el layout web.

MARGIN
BORDER
PADDING
CONTENT 300 × 150px
Content

El área donde vive el texto, imagen o contenido real del elemento. Se controla con width y height.

Padding

Espacio interior entre el contenido y el borde. Tiene el mismo color de fondo que el elemento.

Border

Línea visible alrededor del elemento. Puede tener grosor, estilo (solid, dashed) y color propios.

Margin

Espacio exterior que separa este elemento de sus vecinos. Siempre es transparente.

5.2 — box-sizing: el cambio que todo desarrollador necesita

Por defecto (content-box), el width solo mide el contenido — el padding y border se suman encima, haciendo el elemento más grande de lo esperado.

❌ content-box (default)

width: 200px

+ padding: 20px × 2

+ border: 2px × 2

= 244px reales

.caja {
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* Ancho real: 244px ← sorpresa */
}

✅ border-box (recomendado)

width: 200px

padding incluido

border incluido

= 200px exactos

* {
  box-sizing: border-box;
}
.caja {
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* Ancho real: 200px exactos */
}

5.3b

Etiquetas HTML y su display por defecto

Cada etiqueta HTML tiene un display por defecto asignado por el navegador. Conocerlos evita confusiones al aplicar el Box Model.

▣

Etiquetas BLOCK

Aceptan todo el Box Model: width, height, padding y margin en los 4 lados

div section article aside header footer nav main h1 h2 h3 h4–h6 p ul ol li table form blockquote figure hr pre address
▬

Etiquetas INLINE

Aceptan solo parte: ignoran width, height y margin vertical

span a strong em b i small label
⊡

Inline-replaced

Inline por defecto pero sí aceptan width y height

img input button
💡 Solución universal

¿Necesitas Box Model completo en un inline? Cambia su display:

span { display: inline-block; }
a    { display: block; }
Práctica

Pasos para aplicar el Box Model

Cada paso se aplica sobre el mismo HTML de 3 cajas. Guarda y refresca el navegador después de cada bloque.

Paso 1

Reset y base del documento

Antes de tocar las cajas limpiamos lo que el navegador agrega por defecto y definimos la base visual. El box-sizing: border-box en el reset es el concepto más importante — cambia completamente cómo CSS calcula el ancho.

/* Reset universal — elimina márgenes del navegador
   box-sizing: border-box hace que padding y border
   se cuenten ADENTRO del width declarado, no afuera */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* Base del documento */
body {
  font-family: 'Segoe UI', Arial, sans-serif;
  background-color: #f0f4f8;
  padding: 2rem;
  color: #2c3e50;
}

h1 {
  font-size: 1.8rem;
  margin-bottom: 2rem;
  color: #2c3e50;
}
👁

Guarda y refresca. El fondo cambia a gris azulado y el texto tiene la fuente nueva. Los márgenes por defecto del navegador desaparecen.

Paso 2

Box Model en la Caja 1 — propiedad por propiedad

Agregar cada propiedad por separado, guardando y refrescando después de cada una. Así se ve exactamente qué hace cada capa del Box Model.

/* ── CAJA 1 — demostración del Box Model ──
   Agrega una propiedad a la vez y observa el cambio */
#caja-1 {
  /* 1. CONTENIDO: ancho y alto del área de texto */
  width: 300px;
  height: 150px;

  /* 2. PADDING: espacio interior entre texto y borde
     shorthand 2 valores: arriba/abajo | izquierda/derecha */
  padding: 20px 30px;

  /* 3. BORDER: borde visible
     shorthand: grosor | estilo | color */
  border: 4px solid #3498db;

  /* 4. MARGIN: espacio exterior con los vecinos
     shorthand 2 valores: arriba/abajo | izquierda/derecha */
  margin: 30px 0;

  background-color: #ffffff;
}
①

Solo width y height → la caja tiene dimensiones pero el texto toca los bordes

②

Agrega padding → el texto respira dentro de la caja

③

Agrega border → aparece el borde azul. Con border-box sigue siendo 300px exactos

④

Agrega margin → la caja se separa del h1 y de las demás cajas

🔬 Demostración clave: Comenta box-sizing: border-box del reset. La caja pasa de 300px a 368px (300+60padding+8border). Vuelve a descomentar — regresa a 300px exactos.

❌ Sin border-box

padding:+60px
border:+8px
Total:368px

✅ Con border-box

Paso 3

Display y tipos de comportamiento — Caja 2

La caja 2 demuestra los tres tipos de display más usados. Cada cambio de una sola propiedad transforma completamente el comportamiento del elemento en el flujo del documento.

/* ── CLASE BASE para las 3 cajas ── */
.caja {
  background-color: #ffffff;
  border: 2px solid #b2bec3;
  padding: 1rem;
  margin-bottom: 1.5rem;
}

/* display: block — valor por defecto de div
   Ocupa TODO el ancho disponible */
#caja-2 { display: block; width: 300px; }

/* display: inline-block — ocupa solo lo necesario
   pero SÍ acepta width y height */
#caja-2 {
  display: inline-block;
  width: 300px;
  vertical-align: top; /* alinea desde arriba */
}

/* display: none — desaparece completamente */
#caja-2 { display: none; }

Paso 4

Position: relative y absolute — el badge

El truco fundamental: para usar position: absolute en un elemento hijo correctamente, el padre debe tener position: relative. Así el hijo se posiciona dentro del padre, no en la ventana.

/* PASO 4a — Sin relative en el padre
   El badge se va a la esquina de la PANTALLA */
.badge {
  position: absolute;
  top: 0;
  right: 0; /* ← va a la esquina del body */
}

/* PASO 4b — Con relative en el padre ✅
   El badge se posiciona dentro de la caja 2 */
#caja-2 {
  position: relative; /* punto de referencia para el hijo */
}
.badge {
  position: absolute;
  top: 10px;   /* 10px desde el borde de la CAJA */
  right: 10px;  /* 10px desde el borde de la CAJA */
  background-color: #e74c3c;
  color: white;
  padding: 0.25rem 0.6rem;
  border-radius: 20px;
}

Paso 5

Overflow — qué pasa cuando el contenido desborda

La caja 3 tiene height fija insuficiente para su contenido. Los cuatro valores de overflow manejan ese desbordamiento de formas distintas. 

#caja-3 {
  width: 400px;
  height: 100px; /* insuficiente para el texto */
  padding: 1rem;

  /* Prueba uno a la vez y observa el resultado: */
  overflow: visible;  /* default: sale de la caja */
  overflow: hidden;   /* recorta — no es visible */
  overflow: scroll;   /* scrollbar siempre visible */
  overflow: auto;     /* scrollbar solo si hace falta ✅ */
}
visible
El texto sale de la caja sin ningún recorte. Es el comportamiento por defecto del navegador. El texto aparece fuera del borde.

Default — raramente deseable

hidden
El texto que no cabe queda cortado. El usuario no puede verlo ni hacer scroll.

Imágenes con border-radius, animaciones

scroll
Scrollbar siempre visible aunque el contenido quepa en el espacio disponible.

Poco usado — scrollbar aunque no haga falta

auto ✅
Scrollbar aparece solo cuando el contenido realmente lo necesita. La opción más inteligente.

El más usado en producción

🔬 Bonus — overflow y border-radius: Agrega border-radius: 50px y overflow: hidden a la caja 3. El texto queda recortado limpiamente siguiendo la curva. Sin hidden el texto saldría rompiendo el diseño.
Paso 6

Position: sticky y fixed

fixed se ancla a la ventana del navegador — siempre visible sin importar el scroll. sticky se comporta como relative hasta que llegas a un punto del scroll, y ahí se fija. 

/* FIXED — anclado a la VENTANA
   z-index eleva el elemento por encima de otros */
.barra-fixed {
  position: fixed;
  bottom: 0;
  left: 0;
  width: 100%;
  z-index: 100; /* mayor número = encima de todo */
}

/* STICKY — relativo hasta el umbral, luego fijo */
.encabezado-sticky {
  position: sticky;
  top: 0; /* se pega cuando llega a 0px del top */
  z-index: 50;
}

Paso 7

Pseudo-elementos ::before y ::after

Los pseudo-elementos crean contenido visual sin tocar el HTML. Siempre necesitan la propiedad content, aunque esté vacía. 

/* ::before — ANTES del contenido del elemento */
#caja-1::before {
  content: '📦 ';   /* obligatorio — sin él no existe */
  font-size: 1.2rem;
}

/* ::after — DESPUÉS del contenido del elemento */
#caja-1::after {
  content: ' ✓';
  color: #27ae60;
  font-weight: 700;
}

/* Separador decorativo — content vacío '' */
h1::after {
  content: '';          /* existe pero sin texto */
  display: block;
  width: 60px;
  height: 4px;
  background-color: #3498db;
  margin: 0.5rem auto 0;
}

/* Badge con ::after — position: absolute
   mismo concepto del Paso 4 con position */
#caja-3 { position: relative; }
#caja-3::after {
  content: 'OFERTA';
  position: absolute;
  top: 8px;
  right: 8px;
  background-color: #e74c3c;
  color: white;
  padding: 0.2rem 0.6rem;
  border-radius: 20px;
}

Reglas obligatorias de los pseudo-elementos

1
content siempre requerido — sin content: '' el pseudo-elemento no se renderiza aunque tenga todos los demás estilos
2
Se posicionan como cualquier elemento — con position: absolute se comportan igual que un elemento real
3
No existen en el HTML — no se pueden seleccionar con el cursor, no aparecen en el inspector de elementos
4
Usos comunes: separadores decorativos, badges sin HTML extra, íconos antes de listas, subrayados animados en hover, overlays sobre imágenes

Resumen — Temática 5 completa

Box Model

Content → Padding → Border → Margin. Con border-box el width incluye todo.

▣

Display

block acepta todo. inline ignora width/height. inline-block acepta todo pero convive en línea.

📍

Position

Para absolute el padre necesita relative. fixed a la ventana. sticky al scroll.

📜

Overflow

auto es el más usado en producción — scrollbar solo cuando hace falta.

✨

Pseudo-elementos

::before y ::after crean contenido visual sin tocar el HTML. Siempre necesitan content.

🔢

z-index

Controla el orden de apilamiento. Solo funciona en elementos con position distinto de static.
