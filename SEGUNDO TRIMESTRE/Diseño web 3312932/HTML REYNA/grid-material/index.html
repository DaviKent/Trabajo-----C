7.1

Activando Grid y vocabulario esencial

Con display: grid el contenedor se convierte en grid container y sus hijos en grid items. A diferencia de Flexbox, los ítems no se mueven solos — Grid espera que definamos la cuadrícula.

F

Cuadrícula 3×2 — líneas numeradas desde 1

Grid line

Líneas que dividen la cuadrícula, numeradas desde 1 (también -1 desde el final).

Grid track

Espacio entre dos líneas adyacentes — una fila o una columna completa.

Grid cell

La intersección de una fila y una columna. La unidad mínima del grid.

Gap

Espacio entre celdas. Se controla con gap, row-gap o column-gap.

/* Una sola línea activa Grid */
.contenedor {
  display: grid;
  /* Los hijos directos son automáticamente grid items */
  /* Pero sin columnas/filas definidas no se ve nada diferente todavía */
}

Posicionando ítems con líneas

Por defecto Grid coloca los ítems automáticamente. Con grid-column y grid-row puedes posicionar cualquier ítem usando los números de línea.

/* Posicionando con números de línea */
.item {
  grid-column: 1 / 3;    /* línea 1 → línea 3 (2 columnas) */
  grid-column: 1 / -1;   /* primera → última línea (fila completa) */
  grid-column: span 2;   /* ocupa 2 columnas desde donde esté */
  grid-row: span 2;      /* ocupa 2 filas */
}
7.4

Grid Template Areas — el mapa visual del layout

La característica más legible de Grid. El CSS dibuja el layout con nombres. Un punto . deja una celda vacía.

Layout de página completo

header
sidebar
main
footer

CSS que genera ese layout

.pagina {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: 70px 1fr 60px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}

.cabecera  { grid-area: header;  }
.barra-lat { grid-area: sidebar; }
.contenido { grid-area: main;    }
.pie       { grid-area: footer;  }
¿Ves cómo el CSS "dibuja" el layout? Cada fila de grid-template-areas es una fila del grid.

7.5

repeat(), auto-fill y auto-fit

Grids que se adaptan automáticamente. Sin media queries, las columnas se reorganizan solas. La técnica más usada en galerías y grids de tarjetas.

auto-fill con minmax — achica la ventana para verlo

Tarjeta 1

grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));

auto-fill

Crea tantas columnas como quepan. Las vacías siguen ocupando espacio.

repeat(auto-fill, minmax(200px, 1fr))

auto-fit

Igual pero colapsa columnas vacías. Las que tienen contenido se estiran.

repeat(auto-fit, minmax(200px, 1fr))

minmax(min, max)

Tamaño mínimo y máximo para la columna. minmax(200px, 1fr) = mínimo 200px, máximo flexible.

minmax(200px, 1fr)

Alineación en Grid

Dos ejes: justify (horizontal) y align (vertical). Las propiedades del contenedor afectan todos los ítems; las del ítem sobrescriben para uno específico.

justify-items: start

A
B
C

B

justify-items: end

A
B
C

align-self por ítem

start
center
end
/* En el CONTENEDOR — afecta todos los ítems */
.grid {
  justify-items: start | center | end | stretch;  /* horizontal en su celda */
  align-items: start | center | end | stretch;   /* vertical en su celda */
  place-items: center;   /* shorthand: align + justify */
}
/* En el ÍTEM — sobrescribe para ese elemento */
.item { justify-self: center; align-self: end; }

7.7

Grid vs Flexbox: cuándo usar cada uno

No son rivales — son complementarios. Regla de oro: Flexbox para componentes, Grid para layouts de página.

SituaciónFlexboxGrid
Barra de navegación✓
Tarjetas en fila simple✓
Layout de página completo✓
Galería de fotos✓
Formulario con campos alineados✓
Componentes internos (badges, botones)✓
Layouts modernos complejos✓ dentro✓ estructura

Flexbox piensa desde el ítem

"¿Cuánto espacio ocupa este elemento?"

→ Una dimensión (fila OR columna)

↔

Grid piensa desde el contenedor

"¿Cómo divido este espacio en zonas?"

→ Dos dimensiones (filas AND columnas)
