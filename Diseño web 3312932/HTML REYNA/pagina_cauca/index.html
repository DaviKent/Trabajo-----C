Formulario de registro en plataforma de aprendizaje ------------ La startup EdTech AprendeCauca necesita un formulario de registro para su plataforma de cursos en línea. El formulario debe capturar: datos personales, nivel educativo (lista desplegable), área de interés principal (radio — solo una), habilidades previas (checkboxes — múltiple), disponibilidad horaria (select múltiple), una breve presentación (textarea), y aceptación de términos. Usa fieldset para agrupar cada sección lógica.
